================================================================
1) Static 3DGS pipeline (Faz 1 + Faz 2)
================================================================

Mevcut 4D pipeline'in tum codebase'i reuse edilerek tek bir
`cfg.train.static_mode=True` flag ile statik 3D Gaussian Splatting
modu eklendi. Photo-set / sparse-view / tek-frame multi-view
sahneler artik desteklenir.

Faz 1 — static_mode flag + 4D bypass
  * backend/config.py
      - TrainConfig.static_mode: bool = False (yeni)
      - is_static_scene(scene_name) helper: data/<scene>/static.flag,
        images/, ya da colmap-only durumunu auto-detect eder
  * backend/model/trainer.py
      - _apply_deformation static_mode'da identity transform doner
        (deformation MLP + Fourier trajectory bypass)
      - Static phase warmup 0 (statik modda warmup gerekmez)
      - lr_deform = lr_fourier = 0 zorlanir
      - Phase 2.1 auto-promote (static/dynamic mask voting) atlanir
        (statik sahnede dynamic ayrimi anlamsiz)
  * backend/pipeline.py
      - static_mode=True ise foundation modeller (depth/tracks/masks/
        flow) otomatik atlanir
      - 4D-only loss lambda'lari otomatik 0'lanir: lambda_depth,
        lambda_mask_motion, lambda_track, lambda_flow,
        lambda_smoothness, lambda_rigidity, lambda_deform_reg,
        lambda_fourier_reg, lambda_multiview_consistency
      - DeformationField construct skip (minimal placeholder, tum
        parametreler requires_grad=False)

Faz 2 — preset runner
  * scripts/static_3dgs.py (yeni)
      - 4 preset: fast (5-8 dk preview), balanced (30-45 dk
        production), high (2-3 saat profesyonel), premium
        (6-10 saat 4dv.ai-tier)
      - --list-presets, --dry-run, --force, --no-export, --video CLI
      - Photo set support: data/<scene>/images/*.jpg klasoru varsa
        otomatik frames/'a kopyalanir
  * scripts/__init__.py (yeni) — package marker, backend.api'nin
    _apply_preset import edebilmesi icin
  * docs/STATIC_3DGS_ROADMAP.md (yeni) — 5 fazli plan
  * docs/QUALITY_GAP_ANALYSIS.md (yeni) — 4dv.ai parite analizi

================================================================
2) Frontend v6.0 — mode-aware refactor
================================================================

Tek `JobSubmitPanel` icindeki 8 karisik preset (micro/smoke/full/
high/cloud/ultra/ultra_clean/static_max) temizlendi. Frontend
artik "Static 3D" ve "4D Dynamic" olarak iki net moda ayrildi.

Yeni dosyalar
  * frontend/src/components/Static3DSubmit.tsx
      - Photo-set destekli (video upload opsiyonel)
      - 4 preset: fast/balanced/high/premium (scripts/static_3dgs.py
        ile birebir)
  * frontend/src/components/Dynamic4DSubmit.tsx
      - Video upload zorunlu (multi-view N3V auto-detect)
      - 8 preset: micro/smoke/full/high/cloud/ultra/ultra_clean/
        static_max (legacy 4D static-leaning)
      - Foundation toggle korundu

Degisen dosyalar
  * frontend/src/components/JobSubmitPanel.tsx
      - Wrapper'a donusturuldu: mode picker (Static 3D / 4D Dynamic)
        + alt component render
  * frontend/src/components/HyperparameterPanel.tsx
      - Mode prop eklendi
      - GroupSpec.dynamicOnly flag — static modda 4D-only gruplar
        (deformation MLP, Fourier, motion regs, foundation models,
        anti-streak) gizlenir
      - Loss agirliklari ikiye bolundu: mode-shared + 4D-only
  * frontend/src/api.ts
      - JobMode, StaticPreset, DynamicPreset type'lari
      - SubmitJobOptions: artik {mode, preset} zorunlu, eski boolean
        flag'ler kaldirildi
      - submitJob() artik videoFile|null kabul eder (static photo-set)
      - FormData'da mode + preset gonderir
  * frontend/src/App.tsx
      - mode state (localStorage'a persistent: '4dgs.mode' key)
      - JobSubmitPanel'e mode + onModeChange prop
  * frontend/src/App.css
      - .mode-picker, .mode-btn, .submit-panel-mode-banner,
        .preset-duration, .hparam-mode-tag

Backend
  * backend/api.py
      - /process endpoint'ine mode + preset alanlari (single source
        of truth). Eski boolean flag'ler legacy compat icin korundu.
      - mode='static' verildiginde scripts.static_3dgs._apply_preset
        cagrilir, ardindan run_pipeline static_mode=True ile
      - mode='dynamic' + preset string'i legacy boolean'a translate
        edilir (smoke/micro/high/ultra/ultra_clean/static_max/cloud)
      - Video upload artik static modda opsiyonel — sahne klasorunde
        images/, frames/ veya video.mp4 yoksa anlamli hata firlatir
