--- VIEWER REWRITE (v3.7.7 → v3.7.9) ---

frontend/src/components/SplatViewer.tsx tamamen yeniden yazıldı:

v3.7.7 — Cached single-frame swap pattern:
- Mount'ta tüm N PLY'yi paralel fetch (~30 sn)
- RAM'de Blob cache (~1.3 GB için 90 frame)
- currentFrame değişince blob URL'den remove + add (~50-150 ms swap)
- Multi-mode visibility toggle KALDIRILDI (broken)

v3.7.8 — Progressive load:
- v3.7.7'de tüm cache bitene kadar frame 0 bile gözükmüyordu (bad UX)
- Şimdi: frame 0 önce blocking fetch+render → UI ~2 sn'de açılır
- Background prefetch (3 paralel) currentFrame'den genişleyerek
- On-demand fetch+swap (uncached frame'lerde lazy load)

v3.7.9 — Gray screen fix + stale request drop:
- ADD-before-REMOVE swap pattern → gray screen yok
- Single swap loop + pending frame ref → play'de queue overload yok
- Stale (eski) frame requests doğal drop → latest'e direkt swap
- Race condition immunity (mountedRef check her adımda)

Frontend Tauri penceresinde:
- Eski: frame değişiminde gray flash 50-200 ms
- Yeni: smooth atomic transition, kullanıcı gray görmüyor
